# 歇一会儿：关怀优先的产品建议（未实现清单）

## 定位

给工作中的普通人一个不用解释、无需表现、随时能走的小休息角落。小游戏是手段，不是让人持续在线的目标。

建议品牌主张：**歇一会儿，不用把每一分钟都过得有用。**

## 优先级

### 优先：信任与安全感

- 烦恼回收站明确区分「本地写下并清空」与「在线整理」；默认不发送，用户主动选择在线整理时才发送。当前仍是在线优先，此项尚未实施。
- 清空与异步请求隔离：处理期间清空或编辑后，旧结果不能重新显示在页面。当前需要后续单独修复。
- 提供按数据类型清理的本地数据中心（成绩 / 偏好 / 工作表格），明确不清除浏览历史、不上传、不跨设备；删除前确认。
- 失败与无解状态、声音停止、返回大厅、提醒关闭要一致可靠，不新增强制提醒。

### 下一步：让休息更容易

- 大厅加入轻量筛选：想动脑 / 想动手 / 不想动脑；保留现有全部游戏，不靠增加卡片数量解决选择困难。
- 卡片给出交互特点（不计时 / 可撤回 / 有危险），不要标未经统计的精确时长或人气数据。
- 当前“热门”为人工指定推荐，并非访问统计排名；后续可改为“推荐”。

- 桌面端摸鱼布局已固定为“音景 / 倒计时”“解压 / 烦恼”“工作横卡”，避免单列卡片硬撑高度。
- 媒体强度与视差只在用户调节时联动；减少动态开关已移除，避免让用户承担额外设置。
- 恢复中断的游戏（明确是本机存档），难度与重置操作旁说明“重开本局”；离开有进度的对局时可保存或确认。
- 结算提供同等清晰的“再来一局”和“就到这里”，不加断签损失、强制排行榜、积分焦虑。

### 界面表达

- 「娱乐 · 玩一局 / 摸鱼 · 放空一下」可逐步测试更温和的「玩一会儿 / 放空一会儿」。
- 将“老板来了”保留为轻松辅助文案，不作为产品主张；不能承诺不会被发现或替换系统桌面。
- 情绪模块不强行积极，不诊断，不强迫用户先倾诉才能休息。文案可以是“先放这里，不必马上想通”。
- 正文手机端以 14–16px 为主，说明文字不宜长期维持 9–11px；浅灰绿文字需检查对比度。动态效果提供减少动画选项。

## 商业化原则

不在输入烦恼、困难时刻、退出页面或下班提醒时插广告；不出售情绪文本；不把休息变成待完成任务。可在有稳定用户后验证不影响基础游戏的可选主题、音景包与透明赞助。

## 本轮范围

本轮只做旧代码清理，不把以上建议记为已上线功能，不自动发布。

## 本轮关怀版落实记录

已在工作区实现：
- 摸鱼页暖心入口与减少动画选项；声音强度联动画面（雨势 / 摇幅 / 云流）。
- 烦恼回收站默认本地输入与清空，在线整理需主动切换并勾选；异步结果按请求代次隔离，清空/编辑/切换后不回填旧内容。
- 分类别本机数据清理，二次确认，限定 rest: 命名空间，不清除其他应用数据。
- 游戏厅“想动脑 / 想动手”筛选与“不想动脑”休息入口，人工热门改为推荐。
- 工作视图入口改为下方紧凑横卡，解压与倾诉并排；手机用与 DOM 一致的单列顺序。
- 现有基础游戏增加“就到这里”按钮。

仍未实现：全游戏中断存档、跨设备同步、统一所有游戏结算页退出按钮、登录；不能据此声称全部产品建议已完成。
声音为程序合成而非实地录音，已验证技术联动，不将主观真实感视作自动测试通过。
